# Data Structures and Algorithms (DSA)

This repository contains my learning and implementation of Data Structures and Algorithms using the C programming language.

The goal of this repository is to understand how data structures work, how data is organized in memory, and how different operations are implemented using C.

## Topics Covered

- Linked List
- Stack
- Queue
- Circular Buffer
- Binary Tree
- Hashing

## Language

- C

## Objectives

- Understand the fundamentals of data structures.
- Learn how data is stored and managed in memory.
- Implement data structures using C.
- Understand insertion, deletion, searching, traversal, and other operations.
- Improve problem-solving and logical thinking.
- Develop a strong foundation for embedded systems programming.

## Learning Approach

Each topic contains C programs related to understanding the data structure, its operations, and its implementation.

The focus is on understanding the logic behind each implementation rather than simply writing the code.
